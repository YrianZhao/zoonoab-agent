# Antigen-Only Sweep

This folder stores real antigen PDB files collected for the antigen-only screening pass.

Rules:

- Keep only public, downloadable antigen structures or antigen-containing reference structures.
- Do not require antibody, Fab, VHH, scFv or IgG partners for inclusion.
- If a disease rank has no suitable public antigen structure, record it as `not_found` and skip.
- Use the batch markdown files in this folder to continue the sweep in rank order.
