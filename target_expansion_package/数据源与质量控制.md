# 数据源、范围与质量控制

| 数据用途 | 权威来源 | 备注 |
|---|---|---|
| 疾病–人类靶点主干 | Open Targets Platform 26.06 | 使用 `association_overall_direct` 全量直接关联 |
| 目标元数据与 UniProt 映射 | Open Targets `target` dataset | 以 approvedSymbol/Ensembl target ID 为主键；无 UniProt 映射者不丢弃 |
| 疾病名称 | Open Targets `disease` dataset | 保留 disease ID 与名称 |
| 实验结构检索 | RCSB Search API + Data API | 以 UniProt accession 查询；保留多个候选 |
| 结构下载 | RCSB files endpoint | 默认 `.cif.gz` |
| 预测结构回退 | AlphaFold DB API | 仅在无 RCSB 实验结构时使用 |
| 病原体抗原 | IEDB full exports + UniProt | 与人类靶点主干分流 |

## 质量等级建议

- **S1**：实验结构、物种/UniProt/抗原范围人工核验通过
- **S2**：实验结构，但仅结构域/突变体/复合物，需要切链或范围审查
- **S3**：仅 AlphaFold 预测；需 pLDDT/PAE 审查
- **S4**：仅表位肽/模板/同源结构
- **S5**：无可靠结构，保留序列与表位信息，不下载伪 PDB

## 不应自动化替代的审查

RCSB 的“最高分辨率”不等于“最适合抗体抗原建模”。对 GPCR、离子通道、多域受体、大型支架蛋白、病毒衣壳和糖蛋白，必须优先考虑：
- 抗原可及性
- 胞外域/膜外环
- 真实寡聚体与 biological assembly
- 糖基化和二硫键
- 构建体截短与稳定化突变
- 配体、抗体、融合标签对构象的影响
